# Pinned Codex app-server protocol

This directory is generated by the locally installed, supported Codex binary:

```text
codex-cli 0.149.0-alpha.4.1
codex app-server generate-json-schema --out 0.149.0-alpha.4.1
```

The generator and source protocol are part of the Apache-2.0-licensed
[OpenAI Codex repository](https://github.com/openai/codex). EXARCH keeps the
generated schemas in source control so protocol changes are reviewable and
builds do not depend on an unpinned network download. See
[`THIRD_PARTY_NOTICES.md`](../../../../../../THIRD_PARTY_NOTICES.md).

The production adapter refuses other versions. Updating the pin requires a
review of initialization, policy observation, thread/turn lifecycle,
notifications, server-originated approval requests, and interruption fixtures.
The adapter never supplies `approvalPolicy`, `approvalsReviewer`, `sandbox`, or
permission-profile overrides when starting a thread or turn.
